# Arileon (Woodcraft)

React + Vite furniture store with Supabase catalog, admin panel, and Razorpay checkout.

## Run

```bash
npm install
npm run dev
```

## Features

- Shop, cart, product details
- Admin panel at `/admin` (Supabase Auth)
- Checkout + Razorpay at `/checkout`

See **ADMIN_PAYMENTS.md** for setup steps (SQL, admin email, Razorpay keys).
